# 检索下载功能更新说明

本次更新聚焦文献检索、候选池扩展、PDF 下载和前端展示所需的过程记录。更新只提交到当前新版本仓库，不与旧工作区历史做融合。

## 1. 多层级检索计划

新增 `literature_download/query_planner.py` 和 prompt：

```text
docs/prompts/19-query-plan-multilevel.txt
```

原先检索词扩展是扁平字符串列表；现在会生成可展示、可迭代的结构化检索计划：

```text
domain_terms          领域词
problem_terms         问题/任务词
method_terms          方法词
venue_anchor_terms    期刊/会议锚点
seed_terms            种子文献贡献词
negative_terms        排除跑偏领域
executable_queries    实际执行查询
user_iteration_questions  下一轮用户可调整的问题
```

输出文件：

```text
download/query_plan.json
download/search_trace.json
download/frontend_retrieval_summary.json
download/retrieval_report.md
```

## 2. 种子文献点火

新增：

```text
literature_download/seed_ignition.py
```

支持通过 `--seed-papers` 传入综述或核心论文 JSON。种子文献会参与两件事：

1. 抽取 title、abstract、venue、concepts 等内容，补强多层级检索计划。
2. 可作为候选文献直接进入候选池。

种子 JSON 还支持引用文献直入候选池：

```json
{
  "seed_papers": [
    {
      "title": "central seed paper",
      "references": [
        {
          "title": "referenced paper",
          "doi": "10.xxxx/xxxxx",
          "arxiv_id": "2501.00000"
        }
      ]
    }
  ]
}
```

`references`、`cited_references` 或 `reference_papers` 中的条目会展开为 `source=seed_reference` 的候选，进入预筛、打分和下载排序。

相关 CLI 参数：

```text
--seed-papers PATH
--no-seed-candidates
```

## 3. DOI 与期刊来源追溯

新增：

```text
literature_download/doi_enrichment.py
```

对候选文献执行 DOI/title 元数据增强，优先调用：

```text
Crossref
OpenAlex
DOI landing page / publisher page
```

追溯内容包括：

```text
venue / journal
publisher
ISSN / ISBN
year
landing_page_url
pdf_url / oa_url
cited_by_count
concepts
```

输出文件：

```text
download/doi_enrichment_report.json
```

可以用 `--skip-doi-enrich` 跳过该阶段。

## 4. 浏览器/出版社页面元数据探针

新增：

```text
literature_download/browser_metadata_probe.py
```

该脚本用于对已有候选文献进一步追溯 DOI 或出版社 landing page。若环境安装了 Playwright，会使用浏览器打开页面并抽取 meta、link 和 JSON-LD；若没有 Playwright，会回退到 requests 页面解析。

示例：

```bash
python literature_download/browser_metadata_probe.py \
  --input output/run/download/selected_candidates.json \
  --output output/run/download/browser_metadata_report.json \
  --limit 5
```

输出：

```text
download/browser_metadata_report.json
```

## 5. 下载器扩展

新增：

```text
literature_download/pdf_resolver.py
```

下载器不再只依赖 arXiv 或单个 `oa_url`，而是统一解析多个 PDF 候选来源：

```text
本地 library/pdfs
arXiv direct PDF
OpenAlex open_access / locations
Unpaywall
Crossref link
IEEE landing page / stamp URL
publisher landing page
```

下载结果会记录：

```text
download/download_attempts.json
download/manual_download_queue.json
```

当没有可直接下载的 PDF 时，候选会进入人工下载队列。

## 6. 浏览器辅助人工下载

新增：

```text
literature_download/browser_assisted_download.py
```

用于处理高校账号、出版社登录、IEEE Xplore 等需要用户授权访问的下载场景。脚本不会绕过权限，只负责：

```text
读取 manual_download_queue.json
打开候选 landing page
等待用户在浏览器中登录和下载
扫描 Downloads 目录
复制 PDF 到 library/pdfs
记录 manual_download_confirmations.json
```

示例：

```bash
python literature_download/browser_assisted_download.py \
  --queue output/run/download/manual_download_queue.json
```

## 7. 前端展示报告

新增：

```text
literature_download/frontend_report.py
```

每次检索下载阶段会生成面向前端展示的摘要：

```text
download/frontend_retrieval_summary.json

```

内容包括：

```text

扩展检索词
多层级检索计划
每个来源和查询的命中数量
候选文献期刊/会议分布
候选来源分布
选中文献
下载结果
DOI/出版社追溯摘要
```

## 8. IEEE 接口调整

更新：

```text
literature_download/ieee_search.py
```

将 IEEE 检索接口调整为官方 IEEE Xplore API 形式：

```text
https://ieeexploreapi.ieee.org/api/v1/search/articles
```

并为 Full-Text API 预留了下载入口。实际全文下载仍取决于 IEEE API 产品权限和机构授权。

## 9. GPT-5 系列兼容

更新：

```text
backend/llm_client.py
analysis_pipeline/pipeline_common.py
```

对 `gpt-5*` 模型使用 Responses API 的流式调用，兼容当前网关要求：

```text
input 使用 list 结构
stream=True
收集 response.output_text.delta
```

API key 仍通过本地 `.env` 或 `env.yaml` 配置，不写入仓库。

## 10. 统一 CLI 参数

`analysis_pipeline/unified_literature_pipeline.py` 新增参数：

```text
--max-queries
--seed-papers
--no-seed-candidates
--skip-doi-enrich
```

示例：

```bash
python analysis_pipeline/unified_literature_pipeline.py \
  "gpu并行加速编程在电力系统优化问题中的应用" \
  --sources openalex,arxiv \
  --max-queries 8 \
  --max-results 5 \
  --max-papers 5 \
  --seed-papers seeds.json \
  --output-dir output/run
```
